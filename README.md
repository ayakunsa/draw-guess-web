# Meadowmint Draw（draw-guess-web）

一个纯前端的「你画我猜」小游戏

## 定位

- **新建独立项目**
- 复用方式：从 ai-draw-guess **复制纯函数模块并改写为 TypeScript**，移植文件头注释标明来源路径，便于上游升级时手动同步。
- 已按用户决策**去掉 Live2D 21 套角色（约 511MB + 专有 Cubism Core）**：无 `avatar-renderer`、无专有运行时、无服务端、无多模型 Key。
- 技术栈：Vite 5 + React 18 + TypeScript + Tailwind 3.4 + GSAP + lucide-react；`npm run build` 输出静态文件到 `dist/`。零后端、默认零外部请求（AI 为可选添头，见下）。

## 开发

```bash
npm install
npm run dev
npm run build
```

**Windows 用户（便于把项目发给别人测试）**：双击项目根目录的 `启动游戏.cmd`。它会自动检查 Node.js、首次自动 `npm install`、启动本地服务器并打开浏览器；关掉黑色命令行窗口即退出。首次安装依赖需要联网。

## 变量

见 `src/content.ts`：`[BRAND]`、`[WORD_LIST]`、`[ROUNDS]`、`[TIMER]`、`[CREDIT]`（默认值已替换，页脚保留 VibeFather 署名）。


## 玩法与模式（本地热座双人）

**同机双人、遮挡交接**：不是联网房间、不是人 vs AI，也不是按排序猜谜。两人共用一台设备、同一块屏幕，靠全屏遮挡屏交接角色。

### 一局流程
1. 点「开始游戏」→ 看词屏：全屏遮罩只把词显示给画师，猜者回避屏幕；点「记住了，开始画」。
2. 画师作画（画笔/直线/矩形/椭圆、颜色、撤销、清空、导出 PNG、回放、滚轮缩放、拖动平移），点「画完了，交给猜者」；**作画超时（默认 60s）会自动进入交接屏**，不会直接揭晓答案。
3. 交接屏：「请把设备交给猜者」，猜者点「我是猜者，开始猜」。
4. 猜者界面**常驻范围提示**：「分类 · 打N字」（如「动物 · 打一字」「成语 · 打四字」，见 `src/game/hints.ts`），只给范围不暴露谜底。提交一个词 + 把握 0–100 滑杆（仅影响反馈、不计分）；判定原词/别名/四字成语乱序与三字相同，猜中给猜者加 max(1, 4−回合数) 分。猜错只会提示剩余机会，**谜底不显示**；猜错计入本回合次数（默认最多 3 次，设置可调），用尽后本回合结束、答案揭晓、控制权交回画师。
5. 揭晓对错→「下一回合」回到新词（画师重新看词作画）；回合用完结束，可再来一局。

### 角色
- ✏️画师 / 🔎猜者仅为 CSS/SVG 圆牌 + emoji + 文字标签（记分板显示高分方）；已去掉 Live2D 21 套角色（约 511MB + Cubism Core），不是可动立绘。
- 计时仅作画/猜两阶段（默认 60s），看词屏与交接屏不计时。
- 画板配色：点工具条「🎨 调色板」或当前色圆点弹出选色面板，含 24 个预设色（原 12 色 + 深红/橙橘/柠檬黄/青柠/青蓝/靛蓝/品红/褐棕/深灰/银灰/海军蓝/桃粉）、原生取色器与自定义 HEX 输入（仅接受 #RRGGBB）；选中色块即生效并关闭面板；自定义色实时生效，Esc / 点击外部关闭。
- **📖 复盘**：顶部「复盘」按钮打开回合记录页（空闲/揭晓/结束阶段均可开）。左侧回合列表，右侧用独立 canvas 展示该回合**作画快照**，可「重播绘制」逐笔重演（逻辑与画板回放同构）；下方表格列出每次猜测内容、对错与把握。快照在交接（画完或作画超时）时拍下，猜测随提交追加，结果在揭晓时归档。**记录仅存内存**：刷新页面或重开一局即清空，不跨会话保存。
- **撤销 ≠ 回放**：「撤销」移除上一笔（可点多次逐步回退）；「回放」从空白画布按原作画顺序逐笔重播整幅画（按每笔长度计时），播放时可点「跳过回放」直接看完整画。回放中不会落新笔。

### 未实现 / 已知限制
- 未实现：联网房间、账户与多用户、人 vs AI 对手、候选词排序猜谜、服务端持久化（有意保持纯前端零后端）。
- 已知限制：① 猜词超时仍直接揭晓（作画超时已改为进入交接）；复盘记录不持久化，刷新即丢；② 遮挡屏只是界面礼仪、不是安全隔离；③ 题库每局随机不重复，挑战级生僻词仍可能偏难，已有「分类+字数」范围提示缓解；④ AI 为可选添头：不配置模型时只提示「未配置模型」，不发起请求，不影响离线游玩；⑤ 角色固定不轮换（画师/猜者不互换），猜错用尽后是「下一回合回到画师」而非换人。

## 设置菜单（右上角 ⚙）

设置保存在本机浏览器 `localStorage`（key `draw-guess-web:settings:v1`），刷新后仍保留；关闭存储时回落默认值。改动在下一回合/下一局生效。

| 项目 | 默认 | 范围 / 选项 |
|---|---|---|
| 猜词时间 | 60s | 15–300 秒，单位秒（s） |
| 作画时间 | 60s | 15–300 秒，与猜词时间分开计时 |
| 每局回合数 | 5 | 1–8 回合 |
| 每回合猜错上限 | 3 | 1–10 次；用尽后揭晓答案、回到画师 |
| 回放速度 | 标准 | 慢 / 标准 / 快（调快后一局回放约 1–4 秒） |
| 题库分类 | 成语 | 成语 / 动物 / 食物 / 物品 / 职业 / 动作 / 故事 |
| 难度 | 入门 | 入门 / 进阶 / 挑战（显示各档词数） |
| AI 辅助 | 未启用 | 可选添头：填写服务商/模型/API Key 并勾选启用后生效；未配置或关闭时零请求、离线可玩；API Key 仅存本机、密码框不回显 |

## AI 辅助（可选添头 · 不影响纯前端玩法）

游戏默认**零后端、零外部请求、双击即玩、离线可用**。AI 只是添头：未填 Key / 未勾选「启用 AI 辅助」时，「AI 辅助猜」「AI 起稿画」只提示「未配置模型」，不发任何请求，也不影响正常游戏。

### 配置（以 AMD TokenLab 为例）

1. 右上角设置 → AI 辅助：服务商选 **AMD TokenLab**（Base URL 自动填为 `https://api.tokenlab.amd.com/v1`）。
2. 模型：AMD 要求**精确模型 ID**，从下拉选（如 `Gemma-4-31B-IT` / `DeepSeek-V4.1-Flash` / `Qwen3.8-27B`），或选「自定义」手动输入；名称大小写敏感，须与 AMD LAB 控制台一致。
3. 填 API Key，勾选「启用 AI 辅助」，再按需勾选「猜题时允许 AI 辅助猜」「画画时允许 AI 起稿」。点「测试连接」验证。
4. 浏览器直连 AMD TokenLab 常被 **CORS** 拦截（服务端如 DSH 不受此限，所以 DSH 通、网页不通）。若测试连接报网络/CORS 错误：双击项目根目录 `启动 AI 代理.cmd`，把 Base URL 改成 `http://127.0.0.1:8787/v1`，Key 与模型不变，再测一次。

### 本地代理说明

- `proxy/ai-proxy.mjs` 仅用 Node 内置模块，监听 `127.0.0.1:8787`，OPTIONS 返回 CORS 头并把 `/v1/chat/completions` 原样转发到 TokenLab；**不存 Key、不打印 Key、不做开放代理**（目标地址固定）。
- 可在启动代理前设置环境变量 `AMD_API_KEY`，由代理用它覆盖浏览器 Key（此时页面 Key 可留空，避免明文存 localStorage）。
- 不启动代理时游戏一切照旧；配置其他直连可用的服务商（OpenRouter 等）无需代理。
